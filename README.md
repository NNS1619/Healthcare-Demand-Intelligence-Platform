# Healthcare-Demand-Intelligence-Platform
Pharma demand-forecasting system that predicts drug stocking needs for the first 12 months post-launch, and tests whether healthcare-domain signals (population, reimbursement, competitor entry) improve forecast accuracy over historical-sales-only models.

## Research Question
Do domain-informed features add measurable value over historical-only forecasting, and does that value vary by forecast horizon or product maturity?
